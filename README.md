# Banco de Horas

Apps (PWA) para acompanhar o banco de horas dia a dia, mês a mês e a projeção até o fechamento do ciclo de 6 meses.

- `/marcos/`: Tab. 14 (8:00/11:00/13:00/18:00), com botão de bater ponto
- `/matheus/`: Tab. 7 (8:00/12:00/13:30/17:30), com seletor de ano e mês, resumo anual e plano com meta e prazo

Os dados ficam só no aparelho de cada pessoa (localStorage). Use **Exportar backup** / **Importar backup** em Ajustes.

## Publicar
Settings → Pages → Branch `main`, pasta `/ (root)` → Save.
